# 知识地图

```text
区块链：共享的状态与有序交易记录
├── 区块：高度 / 哈希 / 父哈希
│   └── 交易被包含的位置 → 确认与最终性 → 重组处理
├── 账户：私钥 → 公钥 → 地址
│   └── 钱包与签名 → 授权交易 → 广播
└── 交易 → EVM 执行 → 回执（结果 / Gas / 日志）
    └── Solidity 合约 → ERC-20（整数精度 / 授权 / 转账）
        ├── Foundry（单测 / fuzz / invariant / 安全）
        ├── viem（RPC 读写）→ wagmi（React 集成）→ DApp
        └── 支付事件 → 后端同步 → 幂等 / 确认 / 重组
            └── 订单业务状态 → 商户交易记录 → 支付网关
```

Ethereum / L2 是执行环境维度，影响链标识、手续费和最终性策略；不能把不同链上的交易混在一起。

当前学习入口：[第 1 天](../01-blockchain-basics/DAY-01.md)。专题复习：[区块、交易与回执](../01-blockchain-basics/01-blocks-transactions-receipts.md)。其余仅为前置与依赖关系，不表示已经学习或掌握。

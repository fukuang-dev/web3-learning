## 三、12 周学习路线

### 第一阶段：第 1～2 周，区块链基础

学习内容：

- 区块、交易、区块高度、区块哈希。
- 公钥、私钥、地址。
- 钱包工作原理。
- 钱包签名与交易签名。
- Gas、Gas Limit、Gas Price。
- EVM 工作原理。
- 智能合约。
- ERC-20。
- Ethereum 和 Layer 2。

实战：

- 使用区块浏览器分析真实测试交易。
- 使用 viem 读取链上区块和交易信息。
- 理解交易从签名到上链的完整流程。

阶段目标：能够理解并解释链上交易。

### 第二阶段：第 3～4 周，Solidity

学习内容：

- Solidity 语法。
- 数据类型。
- 函数及可见性。
- View、Pure、Payable。
- Modifier。
- Mapping、Struct、Array。
- Event、Error、Require。
- 合约继承。
- Interface、Library。
- ERC-20。
- OpenZeppelin。

实战：

- 计数器合约。
- 简单资金管理合约。
- ERC-20 测试代币。
- 转账、授权、TransferFrom。
- 合约事件。

阶段目标：能够独立编写简单智能合约。

### 第三阶段：第 5～6 周，Foundry 与合约安全

学习内容：

- Foundry。
- Forge、Cast、Anvil。
- 编译、部署和调试。
- 单元测试。
- Fuzz Testing。
- Invariant Testing。
- OpenZeppelin。
- 重入攻击。
- 权限控制漏洞。
- 整数精度问题。
- Oracle 操纵风险。
- Checks-Effects-Interactions。

实战：

- ERC-20 完整测试。
- Fuzz 测试。
- 本地部署。
- 模拟常见漏洞。
- 修复并验证漏洞。

阶段目标：能够独立测试和调试智能合约。

### 第四阶段：第 7～8 周，Web3 前端

学习内容：

- wagmi。
- viem。
- 钱包连接。
- 链上数据读取。
- 合约读写。
- 交易签名。
- 交易状态监听。
- Event 事件监听。
- RPC 节点。
- React 与智能合约交互。

实战：

- React 钱包连接。
- 钱包地址和链 ID 展示。
- ERC-20 余额查询。
- 代币转账。
- 授权。
- 交易状态监听。

阶段目标：独立完成 Web3 DApp 基础开发。

### 第五阶段：第 9～12 周，Web3 商户支付网关

项目名称：

Web3 Merchant Payment Gateway

技术方向：

前端：
- React。
- TypeScript。
- Vite。
- wagmi。
- viem。

智能合约：
- Solidity。
- Foundry。
- OpenZeppelin。

后端：
- Node.js。
- TypeScript。
- 数据库。
- 链上事件监听。

核心功能：

1. 商户创建支付订单。
2. 生成唯一订单号。
3. 指定支付金额和代币。
4. 用户连接钱包。
5. 用户使用测试 ERC-20 代币付款。
6. 智能合约验证支付。
7. 监听链上支付事件。
8. 后端同步交易信息。
9. 更新订单状态。
10. 展示商户交易记录。
11. 提供交易哈希和区块浏览器链接。
12. 订单状态查询。
13. 防止重复处理同一笔交易。

特别关注：

- 订单创建与支付状态。
- 交易提交与交易确认。
- 交易失败与订单超时。
- 链上事件与后端同步。
- 交易幂等性。
- 区块重组及确认数。
- 支付金额精度。
- 商户资金安全。

项目必须拆分为多个里程碑，每完成一个里程碑再进入下一阶段。

最终形成完整 GitHub 作品集。

所有练习使用测试代币和测试网络，禁止使用真实资金、真实用户私钥或主网资金。

## 四、教学模式

采用混合模式：

理论学习 + 代码演示 + 动手练习 + 项目实战。

每天计划投入 1～2 小时。

每次学习按照以下顺序：

1. 知识讲解：解释概念、原理和实际应用场景。
2. 代码演示：提供可运行代码，解释关键实现。
3. 动手练习：布置练习题，不提前泄露完整答案。
4. 作业检查：检查我的代码，解释问题和修改原因。
5. 知识测试：通过问答或代码题检查掌握情况。
6. 学习归档：将当天内容保存到仓库。
7. 进度更新：维护学习进度和下一步任务。

不要一次性生成全部教程。

每次只推进当前学习任务。

如果我没有掌握当前知识点，不要为了赶进度直接进入下一个模块。

## 1. 整体评价

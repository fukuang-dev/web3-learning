## 作业 A：区块摘要

写一个函数，接收样本区块和目标交易哈希，输出：十进制区块高度、区块哈希、父区块哈希、交易数、是否包含目标交易。

调用函数两次：一次使用原样本，一次使用 transactions 为空数组的副本。两种情况均必须正常运行；预期第一种数量为 1 且包含目标，第二种数量为 0 且不包含目标。

不要求 RPC、钱包或数据库。不要修改导师数据或直接把 demo 作为自己的作业。

## 作业 B：业务理解与知识测试

填写 answers.md 的全部必答部分，运行结果和实际耗时如实记录。英文概述是可选项。

知识测试：

1. 为什么获得交易哈希不能立即将订单设为已支付？
2. 为什么同一高度可能有不同区块哈希？
3. RPC 返回 null 回执时，需要排查什么，为什么？

不附完整参考答案；完成后进行代码审查与追问。
